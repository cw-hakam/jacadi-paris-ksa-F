# Google Stitch MCP Server Integration

This document outlines the Model Context Protocol (MCP) server integration for **Google Stitch** within the Lille & Nest workspace.

---

## 🛠️ Configuration Overview

- **Configuration File Location**: [`.agents/mcp_config.json`](../.agents/mcp_config.json)
- **Server Name**: `stitch`
- **Endpoint URL**: `https://stitch.googleapis.com/mcp`
- **Transport Mechanism**: Remote HTTP / Server-Sent Events (SSE) JSON-RPC (`protocolVersion: 2024-11-05`)
- **Authentication**: `X-Goog-Api-Key` HTTP Request Header

### `mcp_config.json` Specification

```json
{
  "mcpServers": {
    "stitch": {
      "serverUrl": "https://stitch.googleapis.com/mcp",
      "headers": {
        "X-Goog-Api-Key": "YOUR_API_KEY"
      }
    }
  }
}
```

---

## ⚡ Available Tools

When connected to Stitch MCP, the AI agent has access to the following design tools:

1. `create_project`: Initializes a new Stitch design project.
2. `list_projects`: Lists all user-owned or shared Stitch design projects.
3. `list_screens`: Retrieves all generated screens and download URLs for a given project ID.
4. `get_screen`: Fetches detailed HTML and screenshot URLs for a specific screen ID.
5. `generate_screen_from_text`: Generates new UI designs from natural language prompts.
6. `edit_screens`: Modifies existing Stitch design screens using AI instructions.
7. `create_design_system`: Defines custom color, typography, and spacing tokens for Stitch.
